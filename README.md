# Tax Agent AI — PM Design Exercise

An end-to-end **Product Management design exercise**: how an AI agent resolves sales-tax discrepancies between an internal billing system and a third-party tax platform.

## Live prototype
▶️ **Open the interactive prototype:** [tax-agent-ai demo](https://yutingsun-eat.github.io/tax-agent-ai/)

## What's here
- **`index.html`** — self-contained interactive prototype (two use cases: discrepancy debug + rule-change alert)
- **`ONEPAGER.md`** — the design one-pager (problem, assumptions, users, solutions, prototype rationale)

## The two use cases in the prototype
1. **Discrepancy debug** — why does billing vs. tax platform show a $29,860 gap for Q3?
2. **Rule-change alert** — a sales-tax rate change (8.9% → 9.6%) with an old-vs-new tax comparison.

> Built as a think-aloud, clickable artifact for a PM design take-home.
